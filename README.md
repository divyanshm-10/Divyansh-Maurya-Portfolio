 Divyansh Maurya Portfolio

A personal portfolio website for Divyansh Maurya, a Computer Science Engineering student focused on web development, data analytics, data science projects, and clean digital experiences.

This portfolio is built with simple frontend technologies and can be hosted directly with GitHub Pages.

## Live Demo

After hosting with GitHub Pages, your website link will look like this:

```text
https://divyanshm-10.github.io/YOUR-REPOSITORY-NAME/
```

If your repository is named `portfolio`, the link will be:

```text
https://divyanshm-10.github.io/portfolio/
```

## Run Locally

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

No installation or build step is required because this is a static website.

## Upload to GitHub

1. Go to [GitHub](https://github.com/).
2. Click **New repository**.
3. Enter a repository name, for example `portfolio`.
4. Keep the repository **Public**.
5. Click **Create repository**.
6. Upload all project files, including:
   - `index.html`
   - `style.css`
   - `script.js`
   - all images
   - resume PDF
   - `README.md`
7. Click **Commit changes**.

## Host With GitHub Pages

1. Open your GitHub repository.
2. Go to **Settings**.
3. Click **Pages** in the left sidebar.
4. Under **Build and deployment**, choose:
   - **Source:** Deploy from a branch
   - **Branch:** `main`
   - **Folder:** `/root`
5. Click **Save**.
6. Wait for GitHub to publish the site.
7. Copy the live link shown by GitHub Pages.

Your live website will usually be available at:

```text
https://divyanshm-10.github.io/REPOSITORY-NAME/
```

## Show the Website on Google

After the GitHub Pages link is live, Google can discover it automatically, but you can speed it up:

1. Go to [Google Search Console](https://search.google.com/search-console/).
2. Add your GitHub Pages website URL.
3. Verify ownership using the method Google provides.
4. Submit the live URL for indexing.

You can also share your live portfolio link on LinkedIn, GitHub profile README, resume, and internship applications.

## Important Notes

- Keep `index.html` in the main/root folder of the repository.
- Do not rename image or PDF files unless you also update the file names inside `index.html`.
- Replace the Formspree placeholder in `index.html` with your real Formspree endpoint if you want the contact form to send messages directly.
- Update project GitHub links with the actual repository links when each project is uploaded.
